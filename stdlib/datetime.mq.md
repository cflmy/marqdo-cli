## 日期部件

`(天)`

Howard Hinnant 的 civil-from-days 算法，输入为 1970-01-01 起的天数。

**z = 天 + 719468**

**era = z // 146097**

**doe = z - era * 146097**

**yoe = (doe - doe // 1460 + doe // 36524 - doe // 146096) // 365**

**年 = yoe + era * 400**

**doy = doe - (365 * yoe + yoe // 4 - yoe // 100)**

**mp = (5 * doy + 2) // 153**

**日 = doy - (153 * mp + 2) // 5 + 1**

**月 = 月份(mp)**

*{年: 年份(年, 月), 月: 月, 日: 日}*

## 格式化

`(毫秒)`

输出 UTC ISO-8601：`YYYY-MM-DDTHH:MM:SSZ`；毫秒非零时追加
`.mmm`。负数毫秒按 1970 前的 UTC 时间处理。

**秒 = 毫秒 // 1000**

**毫 = 毫秒 % 1000**

**天 = 秒 // 86400**

**日内 = 秒 % 86400**

**时 = 日内 // 3600**

**分 = 日内 % 3600 // 60**

**秒数 = 日内 % 60**

**日期 = 日期部件(天)**

**基 = 补零4(日期.年) + "-" + 补零2(日期.月) + "-" + 补零2(日期.日) + "T" + 补零2(时) + ":" + 补零2(分) + ":" + 补零2(秒数)**

1. `毫 == 0`

   *基 + "Z"*

*基 + "." + 补零3(毫) + "Z"*

## 解析

`(文本)`

解析 `YYYY-MM-DDTHH:MM:SSZ` 或带 `.mmm` 的 UTC 文本，返回 Unix 毫秒。
范围、闰年和格式错误都是可恢复 `datetime.invalid`。

**点 = text.codepoints(文本)**

1. `长度(点) < 20 or 长度(点) > 24`

   *失败("长度不是 20–24 个码点")*

1. `点[4] != 45 or 点[7] != 45 or 点[10] != 84 or 点[13] != 58 or 点[16] != 58`

   *失败("分隔符不符合 YYYY-MM-DDTHH:MM:SS")*

**年文本 = 片段(点, 0, 4)**

**月文本 = 片段(点, 5, 7)**

**日文本 = 片段(点, 8, 10)**

**时文本 = 片段(点, 11, 13)**

**分文本 = 片段(点, 14, 16)**

**秒文本 = 片段(点, 17, 19)**

1. `not 是数字串(年文本) or not 是数字串(月文本) or not 是数字串(日文本) or not 是数字串(时文本) or not 是数字串(分文本) or not 是数字串(秒文本)`

   *失败("日期时间分量必须是数字")*

**年 = 整数(年文本)**

**月 = 整数(月文本)**

**日 = 整数(日文本)**

**时 = 整数(时文本)**

**分 = 整数(分文本)**

**秒 = 整数(秒文本)**

**毫文本 = "0"**

**结束 = 20**

1. `长度(点) >= 24 and 点[19] == 46 and 点[23] == 90`

   **毫文本 = 片段(点, 20, 23)**

   **结束 = 24**

1. `长度(点) != 结束 or 点[结束 - 1] != 90`

   *失败("必须以 Z 结尾")*

1. `not 是数字串(毫文本)`

   *失败("毫秒必须是数字")*

**毫 = 整数(毫文本)**

1. `年 < 1970 or 月 < 1 or 月 > 12 or 日 < 1 or 日 > 每月天数(年, 月)`

   *失败("日期超出范围")*

1. `时 < 0 or 时 > 23 or 分 < 0 or 分 > 59 or 秒 < 0 or 秒 > 59`

   *失败("时间超出范围")*

**毫秒 = 日期序号(年, 月, 日) * 86400000 + 时 * 3600000 + 分 * 60000 + 秒 * 1000 + 毫**

*{ok: true, value: 毫秒}*
