## 解析响应字节

`(字节)`

解析 HTTP/1.1 响应字节。头部按 ASCII 解析，正文保持原始字节；chunked
长度以字节计。成功返回 `{ok:true, value:{status, reason, headers, body}}`。

**头部结束 = 找子串(字节, [13, 10, 13, 10], 0)**

1. `头部结束 < 0`

   *{ok: false, code: "http.invalid", message: "缺少头部结束"}*

**头部 = 切片字节(字节, 0, 头部结束)**

**体 = 切片字节(字节, 头部结束 + 4, 长度(字节))**

**行列表 = []**

**行起 = 0**

**下一行 = 找子串(头部, [13, 10], 0)**

- `下一行 >= 0`

  **行列表 = list.append(行列表, 切片字节(头部, 行起, 下一行))**

  **行起 = 下一行 + 2**

  **下一行 = 找子串(头部, [13, 10], 行起)**

**行列表 = list.append(行列表, 切片字节(头部, 行起, 长度(头部)))**

1. `长度(行列表) == 0`

   *{ok: false, code: "http.invalid", message: "缺少状态行"}*

**状态行 = 字节文本(行列表[0])**

1. `not 状态行.ok`

   *{ok: false, code: "http.invalid", message: "状态行不是 ASCII"}*

**状态字节 = 行列表[0]**

**第一空格 = 找字符(状态字节, 32, 0)**

**第二空格 = 找字符(状态字节, 32, 第一空格 + 1)**

1. `第一空格 < 0 or 第二空格 < 0`

   *{ok: false, code: "http.invalid", message: "状态行格式无效"}*

**状态文本 = 字节文本(切片字节(状态字节, 第一空格 + 1, 第二空格))**

1. `not 状态文本.ok`

   *{ok: false, code: "http.invalid", message: "状态码不是 ASCII"}*

**状态 = 整数(状态文本.value)**

**原因 = 字节文本(切片字节(状态字节, 第二空格 + 1, 长度(状态字节)))**

1. `not 原因.ok`

   *{ok: false, code: "http.invalid", message: "原因短语不是 ASCII"}*

**头 = {}**

**行号 = 1**

- `行号 < 长度(行列表)`

  **行 = 行列表[行号]**

  **冒号 = 找字符(行, 58, 0)**

  1. `冒号 >= 0`

     **名 = 字节文本(切片字节(行, 0, 冒号))**

     **值 = 字节文本(切片字节(行, 冒号 + 2, 长度(行)))**

     1. `名.ok and 值.ok`

        **头 = map.set(头, 名.value, 值.value)**

     2. `true`

        **忽略 = 0**

  2. `true`

     **忽略 = 0**

  **行号 = 行号 + 1**

**传输 = map.get(头, "Transfer-Encoding")**

**解码后 = 体**

1. `传输 == "chunked"`

  **分块 = 解码分块字节(体)**

  1. `not 分块.ok`

     *分块*

  **解码后 = 分块.value**

2. `true`

   **忽略 = 0**

*{ok: true, value: {status: 状态, reason: 原因.value, headers: 头, body: 解码后}}*
