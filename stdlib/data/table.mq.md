## 插入有序

`(已排序, 行, 列)`

**新列表 = []**

**已插入 = false**

**下标 = 0**

- `下标 < 长度(已排序)`

  **当前行 = 已排序[下标]**

  1. `not 已插入 and 当前行[列] > 行[列]`

     **新列表 = list.append(新列表, 行)**

     **新列表 = list.append(新列表, 当前行)**

     **已插入 = true**

  2. `true`

     **新列表 = list.append(新列表, 当前行)**

  **下标 = 下标 + 1**

1. `not 已插入`

   **新列表 = list.append(新列表, 行)**

2. `true`

   **忽略 = 0**

## 设置单元格

`(数据, 目标行, 目标列, 值)`

**列名 = table.columns(数据)**

**新行表 = []**

**行号 = 0**

- `行号 < 长度(数据)`

  **行 = table.row(数据, 行号)**

  1. `行号 == 目标行`

     **新行 = []**

     **列号 = 0**

     - `列号 < 长度(行)`

       1. `列号 == 目标列`

          **新行 = list.append(新行, 值)**

       2. `true`

          **新行 = list.append(新行, 行[列号])**

       **列号 = 列号 + 1**

     **新行表 = list.append(新行表, 新行)**

  2. `true`

     **新行表 = list.append(新行表, 行)**

  **行号 = 行号 + 1**

*表(列名, 新行表)*

## 连接

`(左, 右, 左列, 右列)`

**表头 = list.concat(table.columns(左), table.columns(右))**

**结果行 = []**

**左行号 = 0**

- `左行号 < 长度(左)`

  **左行 = table.row(左, 左行号)**

  **键 = 左行[左列]**

  **右行号 = 0**

  - `右行号 < 长度(右)`

    **右行 = table.row(右, 右行号)**

    1. `右行[右列] == 键`

       **结果行 = list.append(结果行, list.concat(左行, 右行))**

    2. `true`

       **忽略 = 0**

    **右行号 = 右行号 + 1**

  **左行号 = 左行号 + 1**

*表(表头, 结果行)*

## 分组

`(数据, 键列, 值列)`

**结果 = {}**

**行号 = 0**

- `行号 < 长度(数据)`

  **行 = table.row(数据, 行号)**

  **键 = 行[键列]**

  **当前 = map.get(结果, 键)**

  **列表 = []**

  1. `map.has(结果, 键)`

     **列表 = 当前**

  2. `true`

     **忽略 = 0**

  **列表 = list.append(列表, 行[值列])**

  **结果 = map.set(结果, 键, 列表)**

  **行号 = 行号 + 1**

*结果*
