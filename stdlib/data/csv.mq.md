## 解析行

`(文本)`

解析单行 CSV：逗号分隔、双引号包裹、`""` 表示一个字面双引号。
不处理换行、多行字段或首尾空白。未闭合引号和未加引号字段中的双引号
返回可恢复错误。

**点 = text.codepoints(文本)**

**下标 = 0**

**字段 = ""**

**字段表 = []**

**引号内 = false**

**错误 = ""**

- `下标 < 长度(点) and 错误 == ""`

  **字符 = text.from_codepoint(点[下标])**

  1. `引号内 and 字符 == "\""`

     1. `下标 + 1 < 长度(点) and text.from_codepoint(点[下标 + 1]) == "\""`

        **`字段 = 字段 + "\""`**

        **下标 = 下标 + 2**

     2. `true`

        **引号内 = false**

        **下标 = 下标 + 1**

  2. `引号内`

     **字段 = 字段 + 字符**

     **下标 = 下标 + 1**

  3. `字符 == "\""`

     1. `字段 == ""`

        **引号内 = true**

        **下标 = 下标 + 1**

     2. `true`

        **错误 = "csv.invalid_quote"**

  4. `字符 == ","`

     **字段表 = list.append(字段表, 字段)**

     **字段 = ""**

     **下标 = 下标 + 1**

  5. `true`

     **字段 = 字段 + 字符**

     **下标 = 下标 + 1**

1. `错误 != ""`

   *失败(错误, "未加引号字段中出现双引号")*

1. `引号内`

   *失败("csv.unterminated_quote", "引号未闭合")*

*成功(list.concat(字段表, [字段]))*

## 格式化字段

`(文本)`

含逗号、双引号、换行或回车的字段加引号，内部双引号写成 `""`。

**点 = text.codepoints(文本)**

**下标 = 0**

**需要引号 = false**

- `下标 < 长度(点) and not 需要引号`

  **码点 = 点[下标]**

  1. `码点 == 34 or 码点 == 44 or 码点 == 10 or 码点 == 13`

     **需要引号 = true**

  2. `true`

     **忽略 = 0**

  **下标 = 下标 + 1**

1. `not 需要引号`

   *文本*

**`结果 = "\""`**

**下标 = 0**

- `下标 < 长度(点)`

  1. `点[下标] == 34`

     **`结果 = 结果 + "\"\""`**

  2. `true`

     **结果 = 结果 + text.from_codepoint(点[下标])**

  **下标 = 下标 + 1**

*`结果 + "\""`*
