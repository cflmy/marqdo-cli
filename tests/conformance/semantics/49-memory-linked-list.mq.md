## 写32

`(内存, 基址, 值)`

**字节3 = 值 % 256**

**字节2 = 值 // 256 % 256**

**字节1 = 值 // 65536 % 256**

**字节0 = 值 // 16777216 % 256**

**`内存[基址] = 字节0`**

**`内存[基址 + 1] = 字节1`**

**`内存[基址 + 2] = 字节2`**

**`内存[基址 + 3] = 字节3`**

*None*

## 读32

`(内存, 基址)`

*内存[基址] * 16777216 + 内存[基址 + 1] * 65536 + 内存[基址 + 2] * 256 + 内存[基址 + 3]*

## 节点

`(内存, 值, 下一个)`

节点是 8 字节块：偏移 0 存一个字节的值，偏移 1..4 存 next 偏移；0 表示空。

**地址 = 分配(内存, 65536, 8)**

**`内存[地址] = 值`**

> 写32(内存, 地址 + 1, 下一个)

*地址*
