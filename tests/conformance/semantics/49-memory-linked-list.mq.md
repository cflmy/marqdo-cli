## @exec 写32

`params(内存: Memory, 基址: Int, 值: Int)`

`字节3 = 值 % 256`

`字节2 = 值 // 256 % 256`

`字节1 = 值 // 65536 % 256`

`字节0 = 值 // 16777216 % 256`

`内存[基址] = 字节0`

`内存[基址 + 1] = 字节1`

`内存[基址 + 2] = 字节2`

`内存[基址 + 3] = 字节3`

`return None`

## @exec 读32

`params(内存: Memory, 基址: Int)`

`return 内存[基址] * 16777216 + 内存[基址 + 1] * 65536 + 内存[基址 + 2] * 256 + 内存[基址 + 3]`

## @exec 分配

`params(内存: Memory, 容量: Int, 大小: Int)`

`当前位置 = 读32(内存, 0)`

`if 当前位置 + 大小 <= 容量`

`写32(内存, 0, 当前位置 + 大小)`

`return 当前位置`

`else`

`return None`

`end`

## @exec 节点

`params(内存: Memory, 值: Int, 下一个: Int)`

节点是 8 字节块：偏移 0 存一个字节的值，偏移 1..4 存 next 偏移；0 表示空。

`地址 = 分配(内存, 65536, 8)`

`内存[地址] = 值`

`写32(内存, 地址 + 1, 下一个)`

`return 地址`

## @exec 遍历求和

`params(内存: Memory, 头: Int)`

`当前 = 头`

`总和 = 0`

`while 当前 != 0`

`总和 = 总和 + 内存[当前]`

`当前 = 读32(内存, 当前 + 1)`

`end`

`return 总和`
