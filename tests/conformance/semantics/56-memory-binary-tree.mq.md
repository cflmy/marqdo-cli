## 写32

`(内存, 基址, 值)`

**字节3 = 值 % 256**

**字节2 = 值 // 256 % 256**

**字节1 = 值 // 65536 % 256**

**字节0 = 值 // 16777216 % 256**

**`内存[基址] = 字节0`**

**`内存[基址 + 1] = 字节1`**

**`内存[基址 + 2] = 字节2`**

**`内存[基址 + 3] = 字节3`**

*None*

## 读32

`(内存, 基址)`

*内存[基址] * 16777216 + 内存[基址 + 1] * 65536 + 内存[基址 + 2] * 256 + 内存[基址 + 3]*

## 新节点

`(内存, 值)`

每个节点 16 字节：偏移 0 存一个字节的值，偏移 4 存左子，偏移 8 存右子；0 表示空。
节点值必须落在 0..255。

**位置 = 读32(内存, 0)**

**`内存[位置] = 值`**

> 写32(内存, 位置 + 4, 0)

> 写32(内存, 位置 + 8, 0)

> 写32(内存, 0, 位置 + 16)

*位置*

## 插入

`(内存, 根, 值)`

1. `根 == 0`

   *新节点(内存, 值)*

2. `值 < 内存[根]`

   **左 = 插入(内存, 读32(内存, 根 + 4), 值)**

   > 写32(内存, 根 + 4, 左)

   *根*

3. `true`

   **右 = 插入(内存, 读32(内存, 根 + 8), 值)**

   > 写32(内存, 根 + 8, 右)

   *根*

## 遍历

`(内存, 根)`

中序遍历，返回从小到大的值列表。

1. `根 == 0`

   *[]*

**左 = 遍历(内存, 读32(内存, 根 + 4))**

**右 = 遍历(内存, 读32(内存, 根 + 8))**

*list.concat(list.concat(左, [内存[根]]), 右)*
