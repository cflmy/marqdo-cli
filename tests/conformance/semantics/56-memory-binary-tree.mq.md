## @exec 写32

`params(内存: Memory, 基址: Int, 值: Int)`

`字节3 = 值 % 256`

`字节2 = 值 // 256 % 256`

`字节1 = 值 // 65536 % 256`

`字节0 = 值 // 16777216 % 256`

`内存[基址] = 字节0`

`内存[基址 + 1] = 字节1`

`内存[基址 + 2] = 字节2`

`内存[基址 + 3] = 字节3`

`return None`

## @exec 读32

`params(内存: Memory, 基址: Int)`

`return 内存[基址] * 16777216 + 内存[基址 + 1] * 65536 + 内存[基址 + 2] * 256 + 内存[基址 + 3]`

## @exec 新节点

`params(内存: Memory, 值: Int)`

每个节点 16 字节：偏移 0 存一个字节的值，偏移 4 存左子，偏移 8 存右子；0 表示空。
节点值必须落在 0..255。

`位置 = 读32(内存, 0)`

`内存[位置] = 值`

`写32(内存, 位置 + 4, 0)`

`写32(内存, 位置 + 8, 0)`

`写32(内存, 0, 位置 + 16)`

`return 位置`

## @exec 插入

`params(内存: Memory, 根: Int, 值: Int)`

`if 根 == 0`

`return 新节点(内存, 值)`

`else`

`if 值 < 内存[根]`

`左 = 插入(内存, 读32(内存, 根 + 4), 值)`

`写32(内存, 根 + 4, 左)`

`return 根`

`else`

`右 = 插入(内存, 读32(内存, 根 + 8), 值)`

`写32(内存, 根 + 8, 右)`

`return 根`

`end`

`end`

## @exec 遍历

`params(内存: Memory, 根: Int)`

中序遍历，返回从小到大的值列表。

`if 根 == 0`

`return []`

`end`

`左 = 遍历(内存, 读32(内存, 根 + 4))`

`右 = 遍历(内存, 读32(内存, 根 + 8))`

`return list.concat(list.concat(左, [内存[根]]), 右)`

## @exec main

`内存 = memory.new(1, 1)`

`内存[0] = 0`

`内存[1] = 0`

`内存[2] = 0`

`内存[3] = 8`

`根 = 0`

`值表 = [5, 3, 8, 1, 4, 7, 9]`

`下标 = 0`

`while 下标 < 长度(值表)`

`根 = 插入(内存, 根, 值表[下标])`

`下标 = 下标 + 1`

`end`

`return [根, 遍历(内存, 根), 读32(内存, 根 + 4), 读32(内存, 根 + 8)]`
