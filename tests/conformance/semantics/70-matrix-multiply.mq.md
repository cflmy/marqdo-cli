## 矩阵乘

`(左, 右)`

List-of-List 行主序矩阵乘法；调用方保证维度匹配。使用 Int 精确算术。

**结果 = []**

**行号 = 0**

- `行号 < 长度(左)`

  **左行 = 左[行号]**

  **新行 = []**

  **列号 = 0**

  - `列号 < 长度(右[0])`

    **总和 = 0**

    **内号 = 0**

    - `内号 < 长度(左行)`

      **总和 = 总和 + 左行[内号] * 右[内号][列号]**

      **内号 = 内号 + 1**

    **新行 = list.append(新行, 总和)**

    **列号 = 列号 + 1**

  **结果 = list.append(结果, 新行)**
