## 写32

`(内存, 基址, 值)`

**字节3 = 值 % 256**

**字节2 = 值 // 256 % 256**

**字节1 = 值 // 65536 % 256**

**字节0 = 值 // 16777216 % 256**

**`内存[基址] = 字节0`**

**`内存[基址 + 1] = 字节1`**

**`内存[基址 + 2] = 字节2`**

**`内存[基址 + 3] = 字节3`**

*None*

## 读32

`(内存, 基址)`

*内存[基址] * 16777216 + 内存[基址 + 1] * 65536 + 内存[基址 + 2] * 256 + 内存[基址 + 3]*

## 分配

`(内存, 大小)`

简单 bump 分配；调用方保证容量足够。

**位置 = 读32(内存, 0)**

> 写32(内存, 0, 位置 + 大小)

*位置*

## 新节点

`(内存, 值)`

节点 16 字节：偏移 0 存一个字节的值，偏移 4 存边链表头；0 表示空。

**位置 = 分配(内存, 16)**

**`内存[位置] = 值`**

> 写32(内存, 位置 + 4, 0)

*位置*

## 加边

`(内存, 源, 目标)`

边 8 字节：目标 u32 + 下一条边 u32。头插到源节点的边链表。

**边 = 分配(内存, 8)**

> 写32(内存, 边, 目标)

> 写32(内存, 边 + 4, 读32(内存, 源 + 4))

> 写32(内存, 源 + 4, 边)

*None*

## 邻接

`(内存, 节点)`

返回节点值列表；顺序是头插顺序（后加的边在前）。

**当前 = 读32(内存, 节点 + 4)**

**结果 = []**

- `当前 != 0`

  **结果 = list.append(结果, 读32(内存, 当前))**

  **当前 = 读32(内存, 当前 + 4)**

*结果*
