## 连接

`(左, 右, 左列, 右列)`

按 equality 连接两张表；输出表头是左表头接右表头，原表不变。

**表头 = list.concat(table.columns(左), table.columns(右))**

**结果行 = []**

**左行号 = 0**

- `左行号 < 长度(左)`

  **左行 = table.row(左, 左行号)**

  **键 = 左行[左列]**

  **右行号 = 0**

  - `右行号 < 长度(右)`

    **右行 = table.row(右, 右行号)**

    1. `右行[右列] == 键`

       **结果行 = list.append(结果行, list.concat(左行, 右行))**

    2. `true`

       **继续 = 0**

    **右行号 = 右行号 + 1**

  **左行号 = 左行号 + 1**

*表(表头, 结果行)*
