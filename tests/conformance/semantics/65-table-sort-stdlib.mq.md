## 插入有序

`(已排序, 行, 列)`

把一行插入到已按 `列` 升序排列的行列表中；返回新列表，不修改输入。

**新列表 = []**

**已插入 = false**

**下标 = 0**

- `下标 < 长度(已排序)`

  **当前行 = 已排序[下标]**

  1. `not 已插入 and 当前行[列] > 行[列]`

     **新列表 = list.append(新列表, 行)**

     **新列表 = list.append(新列表, 当前行)**

     **已插入 = true**

  2. `true`

     **新列表 = list.append(新列表, 当前行)**

  **下标 = 下标 + 1**

1. `not 已插入`

   **新列表 = list.append(新列表, 行)**

2. `true`

   **忽略 = 0**

*新列表*

## 排序

`(数据, 列)`

按列号升序排序；输入表不变，输出新表。

**列名 = table.columns(数据)**

**行数 = 长度(数据)**

**已排序 = []**

**下标 = 0**

- `下标 < 行数`

  **已排序 = 插入有序(已排序, table.row(数据, 下标), 列)**

  **下标 = 下标 + 1**

*表(列名, 已排序)*
