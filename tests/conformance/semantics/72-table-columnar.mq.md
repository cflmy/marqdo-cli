## 转表

`(列存)`

**列 = 列存["列"]**

**数据 = 列存["数据"]**

**行数 = 0**

1. `长度(数据) > 0`

   **行数 = 长度(数据[0])**

2. `true`

   **忽略 = 0**

  **行 = []**

## 列存排序

`(列存, 目标列)`

**列 = 列存["列"]**

**数据 = 列存["数据"]**

**行数 = 长度(数据[目标列])**

**顺序 = []**

**行号 = 0**

- `行号 < 行数`

  **顺序 = list.append(顺序, 行号)**

  **行号 = 行号 + 1**

**下标 = 1**

- `下标 < 行数`

  **当前 = 下标**

  **新顺序 = []**

  **已插入 = false**

  **位 = 0**

  - `位 < 长度(顺序)`

    **已有 = 顺序[位]**

    1. `not 已插入 and 数据[目标列][已有] > 数据[目标列][当前]`

       **新顺序 = list.append(新顺序, 当前)**

       **新顺序 = list.append(新顺序, 已有)**

       **已插入 = true**

    2. `true`

       **新顺序 = list.append(新顺序, 已有)**

    **位 = 位 + 1**

  1. `not 已插入`

     **新顺序 = list.append(新顺序, 当前)**

  2. `true`

     **忽略 = 0**

  **顺序 = 新顺序**

  **下标 = 下标 + 1**

**新数据 = []**

**列号 = 0**

- `列号 < 长度(列)`

  **新列 = []**

  **位 = 0**

  - `位 < 行数`

    **新列 = list.append(新列, 数据[列号][顺序[位]])**

    **位 = 位 + 1**

  **新数据 = list.append(新数据, 新列)**

  **列号 = 列号 + 1**

*{列: 列, 数据: 新数据}*

## 表相等

`(左, 右)`

**左列 = table.columns(左)**

**右列 = table.columns(右)**

**相等 = 长度(左列) == 长度(右列) and 长度(左) == 长度(右)**

**列号 = 0**

- `列号 < 长度(左列) and 相等`

  1. `左列[列号] != 右列[列号]`

     **相等 = false**

  2. `true`

     **忽略 = 0**

  **列号 = 列号 + 1**

**行号 = 0**

- `行号 < 长度(左) and 相等`

  **列号 = 0**

  - `列号 < 长度(左列) and 相等`

    1. `table.cell(左, 行号, 列号) != table.cell(右, 行号, 列号)`

       **相等 = false**

    2. `true`

       **忽略 = 0**

    **列号 = 列号 + 1**

  **行号 = 行号 + 1**

*相等*
