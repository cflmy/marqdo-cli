## 写32

`(内存, 基址, 值)`

把非负 Int 的低 32 位按大端字节写入区域。

**字节3 = 值 % 256**

**字节2 = 值 // 256 % 256**

**字节1 = 值 // 65536 % 256**

**字节0 = 值 // 16777216 % 256**

**`内存[基址] = 字节0`**

**`内存[基址 + 1] = 字节1`**

**`内存[基址 + 2] = 字节2`**

**`内存[基址 + 3] = 字节3`**

*None*

## 读32

`(内存, 基址)`

同样按大端读取四个字节。

*内存[基址] * 16777216 + 内存[基址 + 1] * 65536 + 内存[基址 + 2] * 256 + 内存[基址 + 3]*

## 分配

`(内存, 容量, 大小)`

区域头四个字节保存下一个空闲偏移。这是顺序分配器：free 只把块交还给调用方，
不在这里实现复用。

**当前位置 = 读32(内存, 0)**

1. `当前位置 + 大小 <= 容量`

   > 写32(内存, 0, 当前位置 + 大小)

   *当前位置*

2. `true`

   *None*

**`内存[0] = 0`**

**`内存[1] = 0`**

**`内存[2] = 0`**

**`内存[3] = 4`**

**第一个 = 分配(内存, 65536, 8)**

**第二个 = 分配(内存, 65536, 16)**

**第三个 = 分配(内存, 65536, 8)**
