## 写大端

`(内存, 基址, 值, 宽度)`

从最低字节开始写，放到 `基址 + 宽度 - 1 - 下标`，因此最终是大端序。
调用方保证 `值` 能放进 `宽度` 字节。

**当前 = 值**

**下标 = 0**

- `下标 < 宽度`

  **`内存[基址 + 宽度 - 1 - 下标] = 当前 % 256`**

  **当前 = 当前 // 256**

  **下标 = 下标 + 1**

*None*

## 读大端

`(内存, 基址, 宽度)`

**值 = 0**

**下标 = 0**

- `下标 < 宽度`

  **值 = 值 * 256 + 内存[基址 + 下标]**

  **下标 = 下标 + 1**

*值*

## 写变长

`(内存, 基址, 值)`

LEB128：每字节低 7 位，最高位表示是否还有后续；返回写入字节数。

**当前 = 值**

**偏移 = 0**

- `当前 >= 128`

  **`内存[基址 + 偏移] = 当前 % 128 + 128`**

  **当前 = 当前 // 128**

  **偏移 = 偏移 + 1**

**`内存[基址 + 偏移] = 当前`**

*偏移 + 1*

## 读变长

`(内存, 基址)`

返回 `[值, 消耗字节数]`。

**值 = 0**

**倍数 = 1**

**偏移 = 0**

**继续 = true**

- `继续`

  **字节 = 内存[基址 + 偏移]**

  **值 = 值 + 字节 % 128 * 倍数**

  1. `字节 < 128`

     **继续 = false**

  2. `true`

     **倍数 = 倍数 * 128**

     **偏移 = 偏移 + 1**

*[值, 偏移 + 1]*
