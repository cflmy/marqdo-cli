## @exec 编码

`params(文本: Text, 内存: Memory, 基址: Int)`

把 Unicode 标量序列按 UTF-8 编码写入 Memory，返回字节长度。
这是 .mq.md 自己实现的编码逻辑，不是 Rust 内建 UTF-8 转换。

`点 = text.codepoints(文本)`

`下标 = 0`

`偏移 = 0`

`while 下标 < 长度(点)`

`码点 = 点[下标]`

`if 码点 < 128`

`内存[基址 + 偏移] = 码点`

`偏移 = 偏移 + 1`

`else`

`if 码点 < 2048`

`内存[基址 + 偏移] = 192 + 码点 // 64`

`内存[基址 + 偏移 + 1] = 128 + 码点 % 64`

`偏移 = 偏移 + 2`

`else`

`if 码点 < 65536`

`内存[基址 + 偏移] = 224 + 码点 // 4096`

`内存[基址 + 偏移 + 1] = 128 + 码点 // 64 % 64`

`内存[基址 + 偏移 + 2] = 128 + 码点 % 64`

`偏移 = 偏移 + 3`

`else`

`内存[基址 + 偏移] = 240 + 码点 // 262144`

`内存[基址 + 偏移 + 1] = 128 + 码点 // 4096 % 64`

`内存[基址 + 偏移 + 2] = 128 + 码点 // 64 % 64`

`内存[基址 + 偏移 + 3] = 128 + 码点 % 64`

`偏移 = 偏移 + 4`

`end`

`end`

`end`

`下标 = 下标 + 1`

`end`

`return 偏移`
