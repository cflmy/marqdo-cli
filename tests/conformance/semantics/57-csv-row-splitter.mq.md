## 分割

`(文本)`

这是 CSV 单行拆分的最小实现：只处理逗号分隔，不支持引号或转义；空字段保留。

**结果 = []**

**当前 = ""**

**点 = text.codepoints(文本)**

**下标 = 0**

- `下标 < 长度(点)`

  **字符 = text.from_codepoint(点[下标])**

  1. `字符 == ","`

     **结果 = list.append(结果, 当前)**

     **当前 = ""**

  2. `true`

     **当前 = 当前 + 字符**

  **下标 = 下标 + 1**

*list.concat(结果, [当前])*
