## 解析

`(文本)`

单行 CSV：逗号分隔、双引号包裹、`""` 表示一个字面双引号。
不处理换行、多行字段或首尾空白。

**点 = text.codepoints(文本)**

**下标 = 0**

**字段 = ""**

**字段表 = []**

**引号内 = false**

- `下标 < 长度(点)`

  **字符 = text.from_codepoint(点[下标])**

  1. `引号内 and 字符 == "\""`

     1. `下标 + 1 < 长度(点) and text.from_codepoint(点[下标 + 1]) == "\""`

        **`字段 = 字段 + "\""`**

        **下标 = 下标 + 2**

     2. `true`

        **引号内 = false**

        **下标 = 下标 + 1**

  2. `引号内`

     **字段 = 字段 + 字符**

     **下标 = 下标 + 1**

  3. `字符 == "\""`

     **引号内 = true**

     **下标 = 下标 + 1**

  4. `字符 == ","`

     **字段表 = list.append(字段表, 字段)**

     **字段 = ""**

     **下标 = 下标 + 1**

  5. `true`

     **字段 = 字段 + 字符**

     **下标 = 下标 + 1**

*list.concat(字段表, [字段])*
