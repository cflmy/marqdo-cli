## @exec 分组

`params(数据: Table, 键列: Int, 值列: Int)`

按文本键列分组，把值列聚合成 Map：键 -> List。输入表不变。

`结果 = {}`

`行号 = 0`

`while 行号 < 长度(数据)`

`行 = table.row(数据, 行号)`

`键 = 行[键列]`

`当前 = map.get(结果, 键)`

`列表 = []`

`if map.has(结果, 键)`

`列表 = 当前`

`else`

`忽略 = 0`

`end`

`列表 = list.append(列表, 行[值列])`

`结果 = map.set(结果, 键, 列表)`

`行号 = 行号 + 1`

`end`

`return 结果`

`return [数据, 分组(数据, 0, 1)]`
