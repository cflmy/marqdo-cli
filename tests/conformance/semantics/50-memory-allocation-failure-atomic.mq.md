## 写32

`(内存, 基址, 值)`

**字节3 = 值 % 256**

**字节2 = 值 // 256 % 256**

**字节1 = 值 // 65536 % 256**

**字节0 = 值 // 16777216 % 256**

**`内存[基址] = 字节0`**

**`内存[基址 + 1] = 字节1`**

**`内存[基址 + 2] = 字节2`**

**`内存[基址 + 3] = 字节3`**

*None*

## 读32

`(内存, 基址)`

*内存[基址] * 16777216 + 内存[基址 + 1] * 65536 + 内存[基址 + 2] * 256 + 内存[基址 + 3]*

## 分配

`(内存, 容量, 大小)`

**当前位置 = 读32(内存, 0)**

1. `当前位置 + 大小 <= 容量`

   > 写32(内存, 0, 当前位置 + 大小)

   *当前位置*

2. `true`

   *None*

## main

分配失败必须保持区域头不变，之后的分配仍从原位置继续。

**内存 = memory.new(1, 1)**

**`内存[0] = 0`**

**`内存[1] = 0`**

**`内存[2] = 0`**

**`内存[3] = 4`**

**失败 = 分配(内存, 65536, 65536)**

**失败后位置 = 读32(内存, 0)**

**成功 = 分配(内存, 65536, 65532)**

**最终位置 = 读32(内存, 0)**

*[失败, 失败后位置, 成功, 最终位置]*
