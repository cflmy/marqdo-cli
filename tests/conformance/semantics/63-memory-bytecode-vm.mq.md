## 运行

`(内存, 程序长度, 栈基址)`

程序从偏移 0 开始，栈从 `栈基址` 开始。指令集：
1 = PUSH 立即数，2 = ADD，3 = MUL，5 = JMP，6 = JZ，7 = HALT。

**指令指针 = 0**

**栈指针 = 0**

**运行中 = true**

**错误 = ""**

- `指令指针 < 程序长度 and 运行中 and 错误 == ""`

  **操作码 = 内存[指令指针]**

  1. `操作码 == 1`

     **`内存[栈基址 + 栈指针] = 内存[指令指针 + 1]`**

     **栈指针 = 栈指针 + 1**

     **指令指针 = 指令指针 + 2**

  2. `操作码 == 2`

     **右 = 内存[栈基址 + 栈指针 - 1]**

     **左 = 内存[栈基址 + 栈指针 - 2]**

     **`内存[栈基址 + 栈指针 - 2] = 左 + 右`**

     **栈指针 = 栈指针 - 1**

     **指令指针 = 指令指针 + 1**

  3. `操作码 == 3`

     **右 = 内存[栈基址 + 栈指针 - 1]**

     **左 = 内存[栈基址 + 栈指针 - 2]**

     **`内存[栈基址 + 栈指针 - 2] = 左 * 右`**

     **栈指针 = 栈指针 - 1**

     **指令指针 = 指令指针 + 1**

  4. `操作码 == 5`

     **指令指针 = 内存[指令指针 + 1]**

  5. `操作码 == 6`

     **条件 = 内存[栈基址 + 栈指针 - 1]**

     **栈指针 = 栈指针 - 1**

     1. `条件 == 0`

        **指令指针 = 内存[指令指针 + 1]**

     2. `true`

        **指令指针 = 指令指针 + 2**

  6. `操作码 == 7`

     **运行中 = false**

  7. `true`

     **错误 = "vm.invalid_opcode"**

1. `错误 != ""`

   *失败("vm.invalid_opcode", "未知指令")*

1. `栈指针 == 0`

   *失败("vm.empty_stack", "没有结果")*

*成功(内存[栈基址 + 栈指针 - 1])*
