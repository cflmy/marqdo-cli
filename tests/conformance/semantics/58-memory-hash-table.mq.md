## 写32

`(内存, 基址, 值)`

**字节3 = 值 % 256**

**字节2 = 值 // 256 % 256**

**字节1 = 值 // 65536 % 256**

**字节0 = 值 // 16777216 % 256**

**`内存[基址] = 字节0`**

**`内存[基址 + 1] = 字节1`**

**`内存[基址 + 2] = 字节2`**

**`内存[基址 + 3] = 字节3`**

*None*

## 读32

`(内存, 基址)`

*内存[基址] * 16777216 + 内存[基址 + 1] * 65536 + 内存[基址 + 2] * 256 + 内存[基址 + 3]*

键 u32 + 值 u32。键 0 表示空槽，因此业务键必须从 1 开始。

## 插入

`(内存, 键, 值)`

线性探测；键已存在时只更新值，不增加元素数。

**容量 = 读32(内存, 4)**

**位置 = 键 % 容量**

**尝试 = 0**

**完成 = false**

- `尝试 < 容量 and not 完成`

  **槽 = 8 + (位置 + 尝试) % 容量 * 8**

  **槽键 = 读32(内存, 槽)**

  1. `槽键 == 0`

     > 写32(内存, 槽, 键)

     > 写32(内存, 槽 + 4, 值)

     > 写32(内存, 0, 读32(内存, 0) + 1)

     **完成 = true**

  2. `槽键 == 键`

     > 写32(内存, 槽 + 4, 值)

     **完成 = true**

  3. `true`

     **尝试 = 尝试 + 1**

1. `完成`

   *成功(None)*

2. `true`

   *失败("hash.full", "哈希表已满")*

## 查找

`(内存, 键)`

遇到空槽即停止；找不到返回 None。

**容量 = 读32(内存, 4)**

**位置 = 键 % 容量**

**尝试 = 0**

**结果 = None**

- `尝试 < 容量`

  **槽 = 8 + (位置 + 尝试) % 容量 * 8**

  **槽键 = 读32(内存, 槽)**

  1. `槽键 == 键`

     **结果 = 读32(内存, 槽 + 4)**

     **尝试 = 容量**

  2. `槽键 == 0`

     **尝试 = 容量**

  3. `true`

     **尝试 = 尝试 + 1**
