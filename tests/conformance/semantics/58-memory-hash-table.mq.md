## @exec 写32

`params(内存: Memory, 基址: Int, 值: Int)`

`字节3 = 值 % 256`

`字节2 = 值 // 256 % 256`

`字节1 = 值 // 65536 % 256`

`字节0 = 值 // 16777216 % 256`

`内存[基址] = 字节0`

`内存[基址 + 1] = 字节1`

`内存[基址 + 2] = 字节2`

`内存[基址 + 3] = 字节3`

`return None`

## @exec 读32

`params(内存: Memory, 基址: Int)`

`return 内存[基址] * 16777216 + 内存[基址 + 1] * 65536 + 内存[基址 + 2] * 256 + 内存[基址 + 3]`

## @exec 失败

`params(代码, 消息)`

## @exec 初始化

`params(内存: Memory, 容量: Int)`

头部 8 字节：0..3 是元素数，4..7 是槽数。槽从偏移 8 开始，每槽 8 字节：
键 u32 + 值 u32。键 0 表示空槽，因此业务键必须从 1 开始。

`写32(内存, 0, 0)`

`写32(内存, 4, 容量)`

`return 成功(None)`

## @exec 插入

`params(内存: Memory, 键: Int, 值: Int)`

线性探测；键已存在时只更新值，不增加元素数。

`容量 = 读32(内存, 4)`

`位置 = 键 % 容量`

`尝试 = 0`

`完成 = false`

`while 尝试 < 容量 and not 完成`

`槽 = 8 + (位置 + 尝试) % 容量 * 8`

`槽键 = 读32(内存, 槽)`

`if 槽键 == 0`

`写32(内存, 槽, 键)`

`写32(内存, 槽 + 4, 值)`

`写32(内存, 0, 读32(内存, 0) + 1)`

`完成 = true`

`else`

`if 槽键 == 键`

`写32(内存, 槽 + 4, 值)`

`完成 = true`

`else`

`尝试 = 尝试 + 1`

`end`

`end`

`end`

`if 完成`

`return 成功(None)`

`else`

`return 失败("hash.full", "哈希表已满")`

`end`

## @exec 查找

`params(内存: Memory, 键: Int)`

遇到空槽即停止；找不到返回 None。

`容量 = 读32(内存, 4)`

`位置 = 键 % 容量`

`尝试 = 0`

`结果 = None`

`while 尝试 < 容量`

`槽 = 8 + (位置 + 尝试) % 容量 * 8`

`槽键 = 读32(内存, 槽)`

`if 槽键 == 键`

`结果 = 读32(内存, 槽 + 4)`

`尝试 = 容量`

`else`

`if 槽键 == 0`

`尝试 = 容量`

`else`

`尝试 = 尝试 + 1`

`end`

`end`

`end`

`return 结果`
