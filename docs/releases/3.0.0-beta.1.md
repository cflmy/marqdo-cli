## What this beta is

A Markdown-native language with its own Rust interpreter: `.mq.md` headings
declare `@exec`/`@knowledge`, Strong/Emph/inline-`Code` carry one statement,
keywords (`if`/`else`/`while`/`end`/`params`/`return`) decide control flow. A
single static callable binding feeds `check`/`run`/`call`/`inspect`/Analysis.

Implemented and covered on the released source: RFC-LANG-0002, lock v4 and
pinned Git packages, Analysis v2 / Trace v2, Tool Protocol v1, Plugin ABI v1
(native + worker), Foreign kernels, Resource Provider v2 through the shipped
worker, official stdlib aliases, and extension selection/lock identity.

## Breaking change

The source language is **not** compatible with pre-RFC Marqdo syntax
(Strong=execute / Emph=return / list=branch/loop / quote=call). Old `.mq.md`
sources are not executable; there is no `--legacy`, syntax switch or downgrade
path. The normative contract is `spec/mapping.md` +
`spec/expression.ebnf`; migration is a rewrite documented in
`docs/migration/README.md`. The earlier `cflmy/marqdo` product line is a
different architecture and is not compatible.

## Independent version axes

Product `3.0.0-beta.1` is independent from: Analysis v2, Trace v2, Tool v1,
Plugin ABI v1, Foreign wire v1, Provider manifest v2, lock v4, markdown profile
`marqdo.md.v1`, the bundled stdlib package (`0.1.0`) and third-party package
versions. `project.marqdo` and Tool `compatibility.marqdo` are enforced: beta
cores require an explicit prerelease range such as
`>=3.0.0-beta.1,<4.0.0`.

## Platform and security policy

- Supported: Linux x86_64 (glibc). The archive ships `marqdo` and
  `marqdo-provider-worker` together; the helper is resolved only as a sibling.
- macOS/Windows: experimental, **not claimed**; the Windows lane is a
  cross-compile check only, and the C ABI plugin/provider/worker paths are not
  claimed there.
- `strict`: Linux-only, Bubblewrap probe-gated L1 (pure language + Math), with
  same-SHA disposable-VM isolation evidence. Unsupported hosts fail closed;
  strict L2 (Worker/Foreign/Provider) is unsupported and refused. `project`
  mode and worker transports are not OS sandboxes.
- Beta-only G4 `WARN`: 9/9 correctness-verified workloads on the fixed
  Woodpecker agent (shared/powersave host, recorded environment). Not a general
  performance guarantee.
- Wasm, macOS/Windows provider worker, uv/npm auto-environments, a package
  registry, JIT, built-in Knowledge/Proof/View and platform installers are
  deliberately deferred.

## Install and verify

```bash
sha256sum -c marqdo-3.0.0-beta.1-x86_64-unknown-linux-gnu.tar.gz.sha256
tar -xzf marqdo-3.0.0-beta.1-x86_64-unknown-linux-gnu.tar.gz
cd marqdo-3.0.0-beta.1-x86_64-unknown-linux-gnu
./marqdo --version
./marqdo run examples/hello.mq.md
./marqdo call examples/factorial.mq.md 阶乘 --arg n=5
```

The archive includes `RELEASE_INFO.json`, `SOURCE_SHA`,
`KNOWN_LIMITATIONS.md`, specs, developer docs, runnable examples and public
Analysis/Trace consumers. Checksums prove content integrity only; they are not
a publisher signature.
