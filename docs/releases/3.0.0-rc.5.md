# Marqdo CLI 3.0.0-rc.5 release notes

Released as a Linux x86_64 (glibc 2.39) prerelease. Tag `v3.0.0-rc.5` on the
tagged release commit; the Gitea release carries the archive, its `.sha256` and
`RELEASE_INFO.json` inside the archive.

## What changed

- The standard library is one explicit external Bundle (`--stdlib-dir`, Bundle
  pin) and the CLI repository no longer contains a `stdlib/` source tree
  (marqdo-cli#11 Phase B). Contract lanes, product tests and the perf harness
  materialize the ecosystem Bundle instead of an in-repo copy.
- The release archive still ships exactly one verified stdlib Bundle
  (`marqdo-stdlib@0.2.0`).
- The migrated performance `print-demo` workload now uses a self-contained
  fixture so the G4 comparison no longer depends on the removed in-repo stdlib
  tree; the paired baseline is the previous release rc.4.

## Known limitations

- Linux x86_64 is the only supported platform; macOS/Windows remain UNSUPPORTED
  for this prerelease line.
- `strict` availability depends on host namespaces; unsupported hosts fail
  closed and do not downgrade.
- See `docs/developers/release-limits.md` for the full list.
