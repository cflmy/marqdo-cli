# RC 3.0.0-rc.4 — shared-node performance evidence (WARN)

- **Date:** 2026-11-25
- **Product:** `3.0.0-rc.4`
- **Source SHA:** `452e9a32bd9e40dba427d4180691c58bab74449e`
- **Class:** shared-node `WARN`, **not** a dedicated-node G4 PASS
- **Approval:** the maintainer (`cflmy`) approved shared-node performance
  evidence for this named RC on 2026-11-25. This exception is RC-only; a
  stable/LTS release requires a dedicated fixed node.
- **Evidence generation:** `docs/evidence/2026-11-25-rc.4-analysis-boundary.md`
  and the packed archives below.

## Environment

- Shared development host: Intel Core i7-8565U, 4 cores / 8 threads, 14 GiB RAM,
  `powersave` governor, Linux `7.0.0-43-generic` x86_64, load average
  `0.24 0.79 1.50` at sampling start.
- The agent runs in a container (`systemd-detect-virt --container` =
  `container-other`); this is explicitly **not** a dedicated node and not a
  QEMU/TCG VM. Its times are not comparable with the release G4 node.
- Baseline and candidate are the shipped release archives, five warmups and
  twenty samples per command, same cwd and same fixture.

## Fixture

101 `.mq.md` modules, 82,094 bytes, 903 units, 100 cross-module references,
nested headings, paragraphs, formulas and code fences. The candidate emitted a
2,739,388-byte Analysis; the schema validator and independent
`analysis_consumer.py` accepted it (101 modules, 100 references).

## Results

| Command | rc.3 p50 / p95 (ms) | rc.4 p50 / p95 (ms) | p95 ratio | peak RSS ratio |
|---|---|---|---|---|
| `check index.mq.md --json` | 18.75 / 19.14 | 20.28 / 20.47 | 1.069 | 1.034 |
| `check index.mq.md --emit out.json` | 36.45 / 37.23 | 50.15 / 51.55 | 1.385 | 1.225 |
| `check index.mq.md --refs --json` | 20.07 / 20.33 | 23.65 / 24.05 | 1.183 | 1.107 |

Artifact size grew from 899,146 to 2,739,388 bytes because it now carries exact
source and the document AST. `--emit` p95 and peak-RSS ratios remain below the
issue's 2.5x budget; no-emit p95 is below 1.15x. `--refs` is a diagnostic
extension, not the ordinary no-emit execution path.

The candidate binary in this measurement is the same shipped rc.4 archive
(`sha256 9c3f166b5e5b8840d39d10019074e4e1c42432fc23e26c69670e64fdcf4e15d8`)
and the baseline is the published rc.3 archive. Correctness was verified before
accepting the timings.

## Limits

This is a `WARN` on a shared host. It must not be cited as a dedicated-node G4
PASS, and it does not extend to LTS. The RC gate manifest records the approval
reference and the `WARN` state.
