## Scope and limits

- Evidence is for the exact tested SHA and this disposable VM only. A root,
  container-only or TCG timing run is never promoted to a security or
  performance claim.
- strict is Linux L1 only (pure language + native Math). strict L2
  (Worker/Foreign/Provider) is unsupported and the flags are refused.
- rlimits are used instead of cgroup-v2 accounting; the network is denied by a
  network namespace rather than a seccomp allowlist; filesystem TOCTOU is
  reduced by read-only mounts but not formally proven against a racing host
  user.
- The VM is not a performance node; do not read these timings as G4.
- The release support claim remains Linux x86_64; macOS/Windows strict is
  fail-closed and unclaimed.
