## Implemented boundary

`check ENTRY --emit PATH` now projects the same prepared facts consumed by
`check`, `inspect`, `run` and `call`:

- exact UTF-8 `modules[].source` and `source_digest`;
- the canonical Markdown AST (`document`) shared with `inspect --ast`;
- one heading index with structured path, parent, mode, mode origin and source
  unit, heading span and complete section span (root covers the whole source);
- anchors, functions, imports, calls with target kind/owner/reason, resources
  with AST-payload digest validation and the explicit diagnostics;
- `project.entry_module_id`, captured `manifest_digest`/`lock_digest`, stdlib
  and static extension identities;
- one `document_refs` resolver used by Analysis, `check --refs` and
  `inspect --refs`, with `resolved`/`not_loaded`/`missing`/`ambiguous`/
  `external`/`outside_scope`/`invalid` states.

The retired duplicate resolver and the post-preparation lock re-read are gone.
`--emit` writes owner-only exclusive bytes through a temporary file and rename
and refuses inputs, directories, symlinks and hard links to inputs.

## Performance (local smoke, not G4)

Fixture: 101 modules, 82,094 source bytes, 903 units, 100 cross-module
references; release builds of rc.3 (baseline archive binary) and the rc.4
candidate, five warmups and twenty samples per command, same host and cwd.

| Command | rc.3 p50/p95 (ms) | rc.4 p50/p95 (ms) | p95 ratio | peak RSS ratio |
|---|---|---|---|---|
| `check index.mq.md --json` | 18.28 / 19.09 | 18.47 / 19.07 | 0.999 | 1.001 |
| `check index.mq.md --emit out.json` | 36.49 / 42.65 | 48.66 / 51.59 | 1.210 | 1.186 |
| `check index.mq.md --refs --json` | 19.09 / 19.66 | 21.99 / 22.51 | 1.145 | 1.093 |

The rc.4 artifact is 2,739,156 bytes (rc.3: 899,146) because it now carries the
exact source and AST. The emit p95 and peak-RSS ratios are below the issue's
2.5x budget; the no-emit p95 ratio is below 1.15. These are development-container
numbers and must not be cited as the dedicated-node G4 result.
