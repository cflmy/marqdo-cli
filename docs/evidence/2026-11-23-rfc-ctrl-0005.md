## Coverage and consumer compatibility

- Semantic fixtures 80–88 cover ordered arms, short-circuiting, fallthrough,
  empty arms, nested loops and branch bodies, contextual identifiers and
  inert prose. Fixture 34 still exercises separately carried nested branches.
- The negative corpus covers unmatched and out-of-order arms, malformed
  transfers, missing closure, function and heading bounds, and possibly
  uninitialized reads on loop exit. Runtime tests cover non-boolean
  conditions, fuel, deadlines and transfer containment at function boundaries.
- CLI tests compare Analysis, Trace and Execution Events source spans in UTF-8,
  bind Trace to the emitted Analysis digest, verify the call graph and prove
  that invalid input stops before execution. A property test compares
  span-independent IR across Markdown list, quote and paragraph containers.
- The separately built `marqdo-lint 0.1.0` binary at repository commit
  `58cea75` read the existing `hello.mq.md` Analysis v2 output. Its current
  alignment logic reports `analysis_incomplete` for native `else if`,
  and it rejects Analysis v3 because it supports only v2. Adoption of the
  new nodes requires an update in the Lint repository.

These results record local implementation and archive verification.
Release inclusion and platform evidence remain subject to the maintainer's
release process.
