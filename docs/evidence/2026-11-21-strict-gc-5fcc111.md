The seven adversarial cases:

1. `strict_child_identity_is_unprivileged_and_namespaced`
2. `strict_child_cannot_read_host_files_but_reads_the_project`
3. `strict_child_cannot_write_outside_or_into_the_project`
4. `strict_child_cannot_escape_via_proc_or_privileges`
5. `strict_child_cannot_reach_the_network`
6. `strict_supervisor_enforces_fd_and_process_limits`
7. `strict_supervisor_enforces_memory_cpu_and_output_limits`

Additional contracts executed by the lane:

* strict positive CLI: `run`, `call`, multi-module, and `--json`
  (`success: true`);
* strict L1 resource boundary: a project `file` resource and a `tcp` resource
  are refused with `permission.denied`;
* every external-execution flag (`--allow-foreign`, read/write/net,
  native/worker plugin, kernel, trace file) exits 2;
* an `@knowledge` payload containing `resource.open` produces **no** host side
  effect under strict;
* a forged `MARQDO_STRICT_ACTIVE=1` is refused in text mode (exit 1) and in
  `--json` mode produces exactly one document with
  `code: strict.identity_invalid` (ADR-0053).
