## Residual risks and non-claims

* Strict L2 (Worker/Foreign/native ABI inheriting the sandbox) is not
  implemented; those flags are rejected. Native ABI is never allowed in strict.
* rlimits are used instead of cgroup-v2 accounting; no cgroup enforcement is
  claimed.
* Filesystem TOCTOU is reduced by read-only mounts but not formally proven
  against a racing host user.
* Network is denied by the network namespace, not a seccomp syscall allowlist.
* **A remote self-hosted security-lane CI run is still required** before a
  release may call G-C CI-verified. `.github/workflows/security-linux.yml`
  defines that lane; `MARQDO_REQUIRE_STRICT_SECURITY=1` makes a missing
  mechanism fail instead of skip.
